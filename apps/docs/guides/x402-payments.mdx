# x402 Payments

AgentDomain uses x402 v2 with USDC on Base mainnet. The protocol network is
`eip155:8453`, and Coinbase CDP verifies and settles each payment.

## Standard headers

- `PAYMENT-REQUIRED`: base64-encoded challenge returned with HTTP 402
- `PAYMENT-SIGNATURE`: base64-encoded signed payload sent on the retry
- `PAYMENT-RESPONSE`: base64-encoded settlement result returned after payment

Use `@agentdomain/sdk` for wallet signing. It parses the challenge, selects the
supported Base exact-payment requirement, creates the official v2 payload and
sets the correct request header.

```ts
const agentDomain = new AgentDomain({ walletClient, publicClient });
const identity = await agentDomain.register({
  wallet: walletClient.account.address,
  preferredName: 'research-agent',
  tld: 'xyz',
});
```

AgentDomain first asks CDP to verify the authorization and only then requests
settlement. A rejected or unavailable facilitator fails closed; the backend does
not automatically bypass CDP with self-settlement. The payment recipient remains
the AgentDomain backend wallet, and the configured treasury allocation is swept
after confirmed settlement.

Legacy x402 v1 headers are accepted temporarily for existing integrations. New
clients should use the v2 headers above.
